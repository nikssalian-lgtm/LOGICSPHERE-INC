# Header logo exports

`logicsphere-original.svg` is preserved unchanged.

The two header exports retain every artwork path and the original cyan fills. The full-page paper background is removed and the viewBox is fitted to the artwork with a 2-unit margin. The light export retains original charcoal lettering; the dark export substitutes near-white for the original charcoal fills. Geometry, lettering, tagline and proportions remain unchanged.

The header selects the appropriate transparent export through CSS, without a white badge or image filters. Other placements continue to use the original asset.
